Calculate the current ratio

Calculating the current ratio as current assets divided by current liabilities, expressed as x:1 to the stated rounding.

Type 2 Calculations BUS-CALC-17

★★★☆☆ · 8 of 32 eligible examination papers, 2019–2025. Difficulty: Easy.

Asks for the current ratio and gives current assets and current liabilities.

See frequency evidence and how ratings work

Stars describe how often this type appeared in past papers; they are not a prediction. 9 past-paper parts belong to this type.

Main plan: Grade 8 Plan · Statement of financial position and ratio calculations

KnowledgeMethodWorked examplePracticeTeach it back

Knowledge

  • Current assets are things the business owns that will turn into cash within a year: cash, money owed by customers (receivables) and inventory.
  • Current liabilities are debts the business must pay within a year, such as money owed to suppliers and overdrafts.
  • Current ratio = current assets ÷ current liabilities, written as x:1 (for example 1.75:1).
  • A ratio below 1 means current assets would not cover short-term debts.
  • Pearson provides the ratio formulae in the exam, but you must know which figures go where and how to round.
  • Usually round to 2 decimal places; follow the instruction exactly if a different rounding is asked for.

Before you begin

  • Meaning of current assets and current liabilities
  • Division and rounding to 2 decimal places

Learn these types first: Statement of financial position: assets and liabilities

Specification: 3.5.1 · 3.5.2

Answer technique: Set out a calculation with working (2 marks)

Method

  1. Find current assets and current liabilities for the year asked. Why: Some figures show several years or extra lines like stock.
  2. Divide current assets by current liabilities. Why: This is the current ratio.
  3. Round as asked and write it as x:1. Why: Ratios are shown against 1.

How each command word is answered

Command wordTimes askedWhat to write
Calculate9Use the Calculate card: write current assets ÷ current liabilities with the figures, then the ratio rounded, as x:1.

Common mistakes

Inferred, not measured: Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

  • Dividing current liabilities by current assets (upside down).
  • Taking inventory away first, which gives the acid test ratio instead.
  • Subtracting the two figures instead of dividing.
  • Not following the rounding instruction.

Worked explanation

  1. Current assets = €26 000. Current liabilities = €14 852.
  2. Current ratio = 26 000 ÷ 14 852 = 1.7506…
  3. To two decimal places: 1.75, written as 1.75:1.
Model answer · written by olevels.com, not an official Pearson mark scheme

Current ratio = current assets ÷ current liabilities = 26 000 ÷ 14 852 = 1.75 (1.75:1).

How the marks are earned

Mark 1: 26 000 ÷ 14 852 set up. Mark 2: 1.75. The correct ratio alone earns both.

Calculation check

  • 26000 ÷ 14852 = 1.75
