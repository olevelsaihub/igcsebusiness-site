Break-even output using contribution

Finding break-even level of output as fixed costs divided by contribution per unit (price minus variable cost per unit).

Type 8 Calculations BUS-CALC-06

★★★☆☆ · 8 of 32 eligible examination papers, 2019–2025. Difficulty: Medium.

Asks how many units, people or items must be sold to break even, and gives fixed costs, variable cost per unit and selling price.

Knowledge

  • Break-even is the level of output where total revenue equals total costs: no profit and no loss.
  • Contribution per unit = selling price − variable cost per unit. It is what each unit adds towards paying the fixed costs.
  • Break-even output = fixed costs ÷ contribution per unit.
  • The answer is a number of units (shoes, people, tubs), not money. Break-even revenue would be break-even output × price.
  • If the answer is not a whole number, round UP, because selling part of a unit is not possible and rounding down would leave a small loss.
  • Use fixed costs for the same period as the question (per day, per month, per year).

Answer technique: Set out a calculation with working (2 marks) · Answer a multiple-choice question

Method

  1. Find fixed costs, selling price and variable cost per unit. Why: These are the only three figures the formula needs.
  2. Work out contribution per unit: price − variable cost. Why: Each unit only covers fixed costs with its contribution.
  3. Divide fixed costs by contribution per unit. Why: This gives how many units cover all the fixed costs.
  4. Round up if not whole and write the units (e.g. 800 dog treats). Why: Break-even is a quantity of output.

Common mistakes

Inferred, not measured: Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

  • Dividing fixed costs by the selling price instead of by contribution.
  • Dividing fixed costs by the variable cost per unit.
  • Giving the answer in money when units were asked for.
  • Rounding down, or misreading the size of the fixed costs.

Worked explanation

  1. From Figure 4: monthly fixed costs €1 000, variable cost per unit €3.25, selling price €4.50.
  2. Contribution per unit = 4.50 − 3.25 = €1.25.
  3. Break-even output = 1 000 ÷ 1.25 = 800.
  4. 800 is a whole number, so no rounding is needed. Answer in units: 800 dog treats a month.
Model answer · written by olevels.com, not an official Pearson mark scheme

Contribution per unit = €4.50 − €3.25 = €1.25. Break-even output = fixed costs ÷ contribution per unit = €1 000 ÷ €1.25 = 800 dog treats.

How the marks are earned

Mark 1: the correct set-up, 1 000 ÷ (4.50 − 3.25). Mark 2: 800 dog treats. Writing 800 with no working earns both marks.

Calculation check

  • 4.50-3.25 = 1.25
  • 1000 ÷ (4.50-3.25) = 800
