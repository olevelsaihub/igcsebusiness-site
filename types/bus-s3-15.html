Fixed and variable costs

Costs that stay the same as output changes and costs that change with output, with examples.

Type 1 3 Business finance BUS-S3-15

★★★☆☆ · 10 of 32 eligible examination papers, 2019–2025. Difficulty: Easy.

The question asks to define fixed or variable costs, pick one from a list, or state one a named business would pay.

Knowledge

  • A cost is money a business spends to produce and sell its goods or services.
  • Output is the number of goods or services a business makes or provides.
  • Fixed costs stay the same whatever the output, e.g. rent, insurance and managers' salaries.
  • Variable costs change directly with output, e.g. raw materials and packaging: make more, spend more.
  • Total cost is fixed costs plus variable costs.
  • To classify a cost, ask: would this bill rise if the business made one more unit?

Before you begin

  • What a cost is
  • What output or production means

Specification: 3.3.1

Answer technique: Define a business term (1 mark) · Answer a multiple-choice question · State or give a point from the case (1 mark)

Method

  1. Ask whether the cost would change if one more unit were produced. Why: This single test separates fixed from variable.
  2. If it changes with output, it is variable; if it stays the same, it is fixed. Why: These are the two meanings the schemes reward.
  3. For State questions, pick a cost that clearly fits the named business's product. Why: The schemes reject costs that are not in the business's context.
  4. For Define questions, mention output and whether the cost changes with it. Why: Without the link to output the definition is incomplete.

How each command word is answered

Command wordTimes askedWhat to write
multiple-choice6Apply the one-more-unit test to each option; rent, insurance and salaries are fixed, materials and packaging are variable.
Define3Link the cost to output: fixed costs do not change with output; variable costs change as output changes.
State2Name one cost that fits the case's product, e.g. the main raw material for a variable cost or rent for a fixed cost.

Common mistakes

Inferred, not measured: Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

  • Defining a fixed cost as a cost that never changes at all, instead of not changing with output.
  • Classing packaging or raw materials as fixed.
  • Giving a cost that does not suit the named business in a State question.
  • Mixing up overdraft charges or commission with fixed costs when only rent fits.

Worked explanation

  1. Command: Define, 1 mark: one clear sentence.
  2. Key words: costs, change, output.
  3. Add an example only to support the meaning, not to replace it.
Model answer · written by olevels.com, not an official Pearson mark scheme

Variable costs are costs whose total changes when the amount of output changes, for example the cost of the flowers bought rises as it makes more arrangements.

How the marks are earned

1 mark for stating that the cost changes as output changes. The example supports the answer but does not earn a separate mark.
