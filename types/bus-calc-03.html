Total cost from fixed and variable costs

Finding total cost by adding fixed cost to variable cost per unit (or per hour) multiplied by output or time.

Type 6 Calculations BUS-CALC-03

★★☆☆☆ · 7 of 32 eligible examination papers, 2019–2025. Difficulty: Easy.

Asks for 'total cost' or 'total monthly cost' and gives fixed costs plus a cost per unit, per item or per hour.

Knowledge

  • Fixed costs do not change when output changes, for example rent or a manager's salary.
  • Variable costs change with output, for example materials for each unit. They are usually given per unit or per hour.
  • Total variable cost = variable cost per unit × number of units (or per hour × number of hours).
  • Total cost = fixed costs + total variable cost.
  • The selling price is not a cost. Leave it out of a total cost calculation.
  • Keep the same time period (per day, per week, per month) and give the answer in the currency shown, usually to 2 decimal places for money.

Before you begin

  • The difference between fixed and variable costs
  • Order of operations: multiply before you add
  • Reading a small table of figures

Learn these types first: Fixed and variable costs

Specification: 3.3.1

Answer technique: Set out a calculation with working (2 marks) · Answer a multiple-choice question

Method

  1. Pick out the fixed cost, the variable cost per unit (or per hour) and the number of units (or hours). Why: Figures tables often include a selling price you must ignore.
  2. Multiply variable cost per unit by the number of units. Why: This gives total variable cost.
  3. Add the fixed cost. Why: Total cost needs both kinds of cost.
  4. Write the answer with its currency and check the time period matches the question. Why: Monthly and daily figures must not be mixed.

How each command word is answered

Command wordTimes askedWhat to write
multiple-choice5Work it out first. Wrong options add fixed cost to one unit's cost, multiply fixed cost by variable cost, or use the selling price. Use the Multiple-choice card.

Common mistakes

Inferred, not measured: Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

  • Adding the fixed cost to the variable cost of only one unit.
  • Multiplying the fixed cost by the variable cost, or adding the number of units to the fixed cost.
  • Using the selling price instead of the variable cost per unit.
  • Forgetting to add the fixed cost at all.

Worked explanation

  1. From Figure 1: fixed costs 555.31 SGD, variable cost per unit 0.93 SGD, output 160 toy carts.
  2. Total variable cost = 0.93 × 160 = 148.80 SGD.
  3. Total cost = 555.31 + 148.80 = 704.11 SGD.
Model answer · written by olevels.com, not an official Pearson mark scheme

Total cost = fixed costs + (variable cost per unit × output) = 555.31 + (0.93 × 160) = 555.31 + 148.80 = 704.11 SGD.

How the marks are earned

Mark 1: putting the right numbers into fixed cost + variable cost per unit × output. Mark 2: the correct total of 704.11 SGD. The correct total on its own earns both marks.

Calculation check

  • 0.93 × 160 = 148.8
  • 555.31+0.93 × 160 = 704.11
