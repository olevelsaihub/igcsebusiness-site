Calculate the acid test ratio

Calculating the acid test ratio as current assets minus inventory, divided by current liabilities.

Type 9 Calculations BUS-CALC-18

★☆☆☆☆ · 2 of 32 eligible examination papers, 2019–2025. Difficulty: Medium.

Asks for the acid test ratio and gives current assets, inventory and current liabilities.

Knowledge

  • Inventory (stock) is goods the business holds to sell. It may take time to sell, so it is not counted as quick cash.
  • Acid test ratio = (current assets − inventory) ÷ current liabilities, written as x:1.
  • It is a stricter test than the current ratio of whether the business can pay its short-term debts.
  • Pearson provides the ratio formulae in the exam, but you must know which figures go where and how to round.
  • Usually round to 2 decimal places.
  • Figures in millions or thousands are fine when all three use the same unit.

Before you begin

  • Current ratio (BUS-CALC-17)
  • Meaning of inventory
  • Using brackets so the subtraction is done first

Learn these types first: Calculate the current ratio

Specification: 3.5.1 · 3.5.2

Answer technique: Set out a calculation with working (2 marks)

Method

  1. Subtract inventory from current assets. Why: Inventory is removed because it is not quickly turned into cash.
  2. Divide the result by current liabilities. Why: This is the acid test ratio.
  3. Round as asked and write it as x:1. Why: Ratios are shown against 1.

How each command word is answered

Calculate2Use the Calculate card: show current assets − inventory, then that answer ÷ current liabilities and the rounded ratio.

Common mistakes

Inferred, not measured: Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

  • Forgetting to take away inventory, which gives the current ratio.
  • Taking inventory away from liabilities instead of from assets.
  • Dividing before subtracting because brackets were left out.

Worked explanation

  1. From Figure 3 (TRY million): current assets 12, inventory 4, current liabilities 7.
  2. Current assets − inventory = 12 − 4 = 8.
  3. Acid test ratio = 8 ÷ 7 = 1.1428…
  4. To two decimal places: 1.14, written as 1.14:1.
Model answer · written by olevels.com, not an official Pearson mark scheme

Acid test ratio = (current assets − inventory) ÷ current liabilities = (12 − 4) ÷ 7 = 8 ÷ 7 = 1.14 (1.14:1).

How the marks are earned

Mark 1: (12 − 4) or 8 ÷ 7 set up. Mark 2: 1.14. The correct answer alone earns both.

Calculation check

  • 12-4 = 8
  • (12-4) ÷ 7 = 1.14
